Politique de Confidentialité

Melissa Photography Paris

Dernière mise à jour : Juillet 2025

1. Collecte des données personnelles

Nous collectons les informations suivantes :

  • Informations de contact : nom, prénom, téléphone, email, adresse
  • Informations de prestation : date, lieu, type de séance photo
  • Données de paiement : via PayPal (nous ne stockons pas les données bancaires )
  • Cookies : pour améliorer votre expérience sur notre site

2. Utilisation des données

Vos données sont utilisées pour :

  • Organiser et réaliser vos séances photo
  • Vous envoyer les galeries et livrables
  • Gérer la facturation et les paiements
  • Vous contacter concernant votre prestation
  • Améliorer nos services

3. Droit à l'image

Important : Les photos et vidéos réalisées peuvent être utilisées à des fins promotionnelles (site web, réseaux sociaux, portfolio) sauf si vous demandez expressément qu'elles restent privées lors de la signature du contrat.

4. Conservation des données

  • Données client : conservées 3 ans après la dernière prestation
  • Photos/vidéos : conservées selon les termes du contrat
  • Données comptables : conservées 10 ans (obligation légale)

5. Vos droits (RGPD)

Vous pouvez :

  • Accéder à vos données personnelles
  • Les rectifier ou les supprimer
  • Vous opposer à leur traitement
  • Demander leur portabilité

6. Cookies

Notre site utilise des cookies pour :

  • Analyser le trafic (Google Analytics)
  • Améliorer votre navigation
  • Mémoriser vos préférences

Vous pouvez gérer vos préférences via le bandeau cookies.

7. Sécurité

Nous mettons en place des mesures techniques et organisationnelles pour protéger vos données contre tout accès non autorisé.
